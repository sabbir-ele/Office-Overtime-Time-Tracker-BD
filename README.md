# Office Time Tracker

An intuitive and efficient Android application designed to track office entry, punch-out times, and calculate working hours or overtime automatically. Built using **MIT App Inventor**.

## Features

- **Custom Office Entry Time:** Set your regular office in-time once via the settings screen using an integrated TimePicker.
- **Persistent Storage:** Saves entry times and punch records across sessions using TinyDB.
- **Punch Out Tracking:** Records real-time punch-out stamps with a single tap.
- **Working Hours & Overtime Calculation:** Automates time difference calculations between entry and exit times.
- **Clean & Lightweight UI:** Minimalist interface tailored for quick daily logging.

## Tech Stack

- **Platform:** MIT App Inventor 2
- **Language:** Visual Block Programming
- **Storage:** TinyDB (Local Key-Value Storage)
- **Target OS:** Android

## Installation

1. Download the latest `.apk` file from the [Releases](../../releases) section.
2. Open the file on your Android device and allow installation from unknown sources if prompted.
3. Launch the app and configure your base entry time from the Settings screen.

## Project Structure

- `*.aia`: Complete project source file (can be imported directly into MIT App Inventor).
- `*.apk`: Pre-built installer ready for Android devices.

## How to Import Source Code

1. Log in to [MIT App Inventor](https://ai2.appinventor.mit.edu/).
2. Go to **Projects** > **Import project (.aia) from my computer**.
3. Select the `.aia` file from this repository.
