# ⏱️ Overtime Tracker

A professional and utility-focused Android application designed for engineers and professionals to track daily duty hours, automate break deductions, and calculate strict full-hour overtime.

---

## 🌟 Features

* **Dynamic Shift Management:** Automatically computes standard shift completion (Entry Time + 9 hours).
* **Automated Lunch Deduction:** Automatically deducts a fixed 1-hour lunch break (01:00 PM – 02:00 PM) based on duty duration.
* **Strict Overtime Calculation:** Enforces integer-only (full-hour floor) overtime counting—no partial fractional minutes.
* **Local Data Persistence:** Safely records daily punch entries and history locally using Room/SharedPreferences with restart protection.
* **PDF Report Generator:** Generates formatted duty and overtime summary sheets with native print and share functionality.
* **Optimized UI/UX:** Clean Material 3 design with full edge-to-edge support and system inset handling.
* **Developer BottomSheet:** Integrated developer profile section featuring contact links and local profile picture integration.

---

## 🛠️ Tech Stack & Architecture

* **Language:** Kotlin
* **UI Toolkit:** Jetpack Compose / Material 3
* **Local Storage:** Room Database & Android SharedPreferences
* **Architecture:** MVVM Pattern
* **Device Target:** Optimized for modern Android devices (Android 14 / HyperOS compatible)

## 📥 Installation

1. Go to the [Releases](https://github.com/sabbir-eee/Overtime-Tracker/releases) section of this repository.
2. Download the latest `Overtime-Tracker-v1.1.0.apk` asset.
3. On your Android phone, enable **Install from Unknown Sources** if prompted.
4. Open the APK file to complete installation.
